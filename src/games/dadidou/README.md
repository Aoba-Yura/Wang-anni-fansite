# 《打地豆》游戏包交接说明

版本：1.1.0
交接日期：2026-09-25  
源版本：`8e4256de4a782267d2211e583aa04671c3e8d700`

## 1. 包内内容

```text
dadidou-game-package-v1.0.0/
├── README.md
├── index.html
├── styles.css
├── game.js
└── assets/
    ├── ink-garden-monochrome.png
    └── redbean-puppy-ink-v5.png
```

这是一个无构建步骤、无第三方依赖、无网络请求的纯静态小游戏。复制整个目录即可运行。

## 2. 本地运行

浏览器直接打开 `index.html` 通常可以运行；为了避免浏览器对本地文件的限制，推荐启动静态服务器：

```bash
cd dadidou-game-package-v1.0.0
python3 -m http.server 8080
```

然后访问：

```text
http://localhost:8080/
```

## 3. 推荐集成方式

### 方式 A：独立页面或 iframe（推荐）

将整个目录放到主项目的静态资源目录，例如：

```text
public/games/dadidou/
```

使用独立路由访问，或嵌入：

```html
<iframe
  src="/games/dadidou/index.html"
  title="打地豆"
  allow="autoplay"
  style="width:100%;height:100dvh;border:0;display:block"
></iframe>
```

iframe 可以隔离全局 CSS、键盘事件和页面滚动规则，集成风险最低。

### 方式 B：合并进现有页面

可以复制 `index.html` 中的 `<main id="gameShell">`，同时加载 `styles.css` 和 `game.js`。采用这种方式时需要处理以下冲突：

- `styles.css` 含有 `html`、`body`、`button` 等全局选择器。
- `game.js` 在 `document` 上监听键盘、指针移动和页面可见性事件。
- 页面中不得重复使用游戏现有的 `id`。
- 主页面若有滚动、缩放或触摸手势，应为游戏区域保留 `touch-action` 设置。

若主项目结构复杂，优先采用独立页面或 iframe。

## 4. 游戏规则

- 单局 60 秒。
- 同一时刻只出现一只红豆。
- 点击或敲击红豆得分；点击空处会中断连击。
- 每第 10 只为朱红红豆，基础分高于普通红豆。
- 命中反馈结束后约 150 毫秒出现下一只；漏掉后约 110 毫秒继续。
- 后半局红豆停留时间会逐步缩短。
- 本地最高分保存在浏览器 `localStorage` 中，键名为 `dadidou-best-v3`。

## 5. 操作方式

- 触屏：直接点红豆。
- 鼠标：移动玩具气锤，点击红豆。
- 键盘：按数字小键盘布局控制九个坑位，`1` 至 `3` 为底排，`4` 至 `6` 为中排，`7` 至 `9` 为顶排。
- `P` 或 `Esc`：暂停或继续。
- 开始页和结算页可按 `Enter` 或空格确认。

## 6. 关键可调参数

主要参数位于 `game.js` 顶部：

| 参数 | 当前值 | 含义 |
|---|---:|---|
| `DURATION` | `60000` | 单局时长，单位毫秒 |
| `EXIT_MS` | `150` | 漏掉后退场动画时长 |
| `HIT_MS` | `190` | 命中反馈动画时长 |
| `HIT_GAP_MS` | `150` | 命中后到下一只之间的间隔 |
| `MISS_GAP_MS` | `110` | 漏掉后到下一只之间的间隔 |

难度曲线位于 `dwellFor(now)`：

- 前 20 秒：1050 毫秒。
- 20 至 45 秒：920 毫秒。
- 最后 15 秒：820 毫秒。

朱红红豆频率位于 `revealTarget(now)`：

```js
const vermilion = (opportunitiesShown + 1) % 10 === 0;
```

## 7. 坑位与红豆的层级规则

这是集成时最需要保持的结构：

1. `.burrow::before`：洞内暗部，位于红豆后方。
2. `.redbean-stage`：红豆升降和裁切容器。
3. `.burrow-lip`：洞口前沿，只遮挡红豆身体下部。
4. `.feedback-layer`：命中水墨反馈。
5. `.hud`：计时、分数和暂停按钮。

对应的核心层级为：

```text
洞内暗部 z=5
红豆舞台 z=12
洞口前沿 z=16
命中反馈 z=24
状态栏 z=30
```

请勿把完整坑位图或草丛图整体放到红豆上方，否则红豆会一直像埋在草丛下面。洞口前沿只能覆盖角色下缘。

## 8. 判定区规则

- 点击判定绑定在 `#redbeanTarget` 上，位置与红豆升降容器同步。
- `updateTargetPosition()` 依据当前坑位的实际矩形位置计算红豆位置。
- 空白区域点击只记为空挥，不应通过坑位上方的独立透明区域命中。
- 更换角色图时，应保持透明背景，并让主体尽量填满画布，避免透明边缘扩大实际点击范围。

## 9. 美术资源替换

### 红豆角色

当前文件：

```text
assets/redbean-puppy-ink-v5.png
```

替换要求：

- PNG 透明背景。
- 建议接近正方形画布。
- 主体居中并尽量填满画布。
- 普通红豆应为黑白图；朱红版本由页面中的 SVG 滤镜自动换色。
- 角色脚部会被洞口前沿遮挡，切勿在图像底部保留过大的透明区域。

### 背景

当前文件：

```text
assets/ink-garden-monochrome.png
```

背景通过 `.game-shell` 的 `background` 属性加载。替换时应保留足够留白，避免与九个坑位和顶部状态栏争抢视觉焦点。

### 坑位

坑位已写成 `index.html` 内的 SVG 矢量路径，不依赖外部坑位图片。修改 `#burrowLip` 可以统一调整九个坑位的前沿形状。

## 10. 响应式与浏览器要求

- 游戏画布最大宽度为 600 像素，高度使用 `100dvh`。
- 支持手机触屏与桌面鼠标。
- 推荐现代版本的 Chrome、Edge、Safari 或 Firefox。
- 宿主页面应允许游戏区域占满可用高度。
- 移动端应保留安全区变量 `env(safe-area-inset-*)`。

## 11. 集成验收清单

- [ ] 60 秒倒计时正常开始并归零。
- [ ] 任意时刻只有一只红豆出现。
- [ ] 红豆从洞内升起，脚部由洞口前沿遮挡。
- [ ] 点击身体可命中，点击红豆上方和坑位空处不会命中。
- [ ] 命中后无需等待固定节拍，能够快速进入下一只。
- [ ] 数字键 1 至 9 与九个坑位对应。
- [ ] 第 10、20、30……只红豆显示为朱红色。
- [ ] 暂停期间倒计时、出场计时和动画逻辑不会继续推进。
- [ ] 手机端没有页面滚动、双击缩放或浏览器边缘遮挡。
- [ ] 重新载入后最高分仍可读取。

## 12. 二次开发提醒

- 游戏逻辑使用单一立即执行函数封装，没有向全局对象暴露 API。
- 若宿主需要控制开始、暂停或读取分数，建议新增明确的自定义事件接口，避免直接操作内部变量。
- 若同页加载多个实例，需要把固定 `id` 改为实例作用域，并将 `document` 级事件监听改为容器级监听。
- 修改坑位布局后，应同时检查 `updateTargetPosition()`、键盘落点和移动端尺寸。
- 发布前至少完成一局鼠标测试和一局触屏测试。
